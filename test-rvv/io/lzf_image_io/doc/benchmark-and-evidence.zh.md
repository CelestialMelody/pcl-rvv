# lzf_image_io Benchmark And Evidence

## Bench CLI

`bench_lzf_image_io` 支持：

- `--case-filter all`
- `--case-filter depth_xyz_640x480`
- `--case-filter yuv422_planar_rgb_640x480`
- `--case-filter yuv422_planar_rgb_production_640x480`
- `--case-filter rgb_buffer_to_cloud_640x480`
- `--iterations <n>`
- `--warmup-iterations <n>`

每个 case 输出平均耗时、total time、checksum 和 pixels。checksum 用于确认两侧输出没有被优化掉，也帮助 summary / manifest 生成器检查日志形状。

## Case 字典

| case | baseline / candidate | timer boundary | 证据角色 |
| --- | --- | --- | --- |
| `depth_xyz_640x480` | scalar reference vs RVV candidate | depth16 buffer 到 `PointXYZRGB` x/y/z，加 checksum | production-shaped diagnostic |
| `yuv422_planar_rgb_640x480` | scalar reference vs RVV candidate | planar U/Y/V 到 `PointXYZRGB` r/g/b，加 checksum | production-shaped diagnostic |
| `yuv422_planar_rgb_production_640x480` | production Std helper vs production RVV helper | planar U/Y/V 到 `pcl::PointXYZRGB` r/g/b，加 checksum | production-detail |
| `rgb_buffer_to_cloud_640x480` | scalar reference vs RVV candidate | RGBRGB buffer 到 `PointXYZRGB` r/g/b，加 checksum | production-shaped diagnostic |
