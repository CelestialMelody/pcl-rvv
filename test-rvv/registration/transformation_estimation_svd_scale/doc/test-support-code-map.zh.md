## Production 与 Test Support 边界

`include/impl/tesvd_scale_candidates.hpp` 仍是 test-only diagnostic（测试专用诊断）主归属。它证明候选数学、checksum（校验和）、Phase 000 board 信号、Phase 020 matrix-local formula shape 和 Phase 063 `Scalar=double` diagnostic scout。它不证明 production dispatch。

真实 production dispatch（生产分流）、fallback（回退路径）和 production symbol asm attribution（生产符号反汇编归属）由 production 源码、`src/test_tesvd_scale.cpp` 的 production-facing TEST、`public-scale` bench case、`dump_bench_rvv` 和 production board summary 共同证明。

| 证据家族 | 归属位置 | 说明 |
| --- | --- | --- |
| ordered / row-source / generic / custom layout double | production 源码 + 对应 `TEST` + 对应 bench + board summary | 已采纳的 production branch 由这四类证据一起证明。 |
| generic / more-generic / row-source all-more-generic | `src/test_tesvd_scale.cpp` + `src/bench_tesvd_scale.cpp` + board summary | 扩大点型和 row-source 证据边界，不自动外推到全部自定义点型。 |
| custom layout / padding / alignment / locality profile | `include/impl/tesvd_scale_support.hpp` + `src/test_tesvd_scale.cpp` + `src/bench_tesvd_scale.cpp` | 解释 layout、order、padding 和 alignment sensitivity。 |
| scalar-double diagnostic / production probes | candidate helpers + production helpers + board summary | 先诊断，再接入，再根据用户确认收口。 |
| correspondence sorted-copy double | production helper + bench + board summary + detail A/B | Phase 072 public-positive，Phase 073 negative family selection，Phase 075 回滚。 |
| staged-selected-cloud / target-sorted / stability | detail A/B bench + board summary | 只保留负向或 unstable 诊断，不进入 production。 |
