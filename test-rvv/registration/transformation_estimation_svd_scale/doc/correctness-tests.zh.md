## 共同输入和断言

输入点云默认是 dense `PointXYZ`，target 由固定 similarity transform（相似变换）生成，scale 不等于 1。

| phase 家族 | 输入 | 说明 |
| --- | --- | --- |
| ordered / `Scalar=double` | Phase 063 / 065 / 068 | 先验证 ordered `PointXYZ -> PointXYZ`，再扩到 ordered generic double。 |
| row-source / `Scalar=double` | Phase 067 / 069 | 先验证 exact `PointXYZ -> PointXYZ`，再扩到 common PCL xyz AoS whitelist。 |
| custom layout / `Scalar=double` | Phase 070 / 071 | 先验证一个 custom layout sample，再补三组 custom layout sampling。 |
| sorted-copy / `Scalar=double` | Phase 072 / 073 / 075 | public positive 先保留，再用同边界 detail A/B 关闭。 |
| generic / more-generic 点型 | Phase 040 / 051 / 053 / 054 | 先补代表点型，再补更多常见 PCL xyz AoS 和 row-source 全交叉。 |
| locality / mitigation | Phase 043 / 045 / 046 / 047 / 048 / 049 / 058 / 060 / 061 | 解释 row-source 局部性、sorted-copy、target-sorted 和 contiguous fast path。 |

断言统一检查 4x4 matrix 最大误差、candidate stats（候选统计）和 fallback / RVV 命中状态。

| no seeded stress | 当前无 | 没有 seeded random stress（带种子随机压力样本）。 |
| board evidence 仍按边界解释 | Phase 041、063、065/066、067、068、069、070、071、072、073 | 只覆盖各自采用边界，不自动外推。 |
| remaining plan | 更多自定义点型、异常 alignment、非法 index/correspondence、broader custom layout double、sorted-copy double family selection、随机压力 | 仍需独立计划。 |
