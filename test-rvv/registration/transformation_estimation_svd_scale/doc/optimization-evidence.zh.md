当前结论先看三层：已采纳的 production behavior、已回滚的 sorted-copy double、以及仍只作为证据扩展的路线。

## 标量路径与 RVV 路径差异

| 维度 | 标量 public scale path | direct-fused-scale-accum production path |
| --- | --- | --- |
| 输入边界 | 父类公开入口先构造 iterator，再计算 centroid 和 demean 矩阵。 | 直接读取 ordered source / target 点对。 |
| 主累加 | Eigen 动态矩阵乘法构造 `H`，再逐列计算 `sum_ss` / `sum_tt`。 | RVV 累加 source sum、target sum、source-target cross sum 和 source square sum。 |
| 后段 | Eigen 3x3 SVD、determinant fix、scale、translation。 | 保留同样的 Eigen 3x3 SVD 和输出构造。 |
| 证据角色 | fallback / Std production baseline。 | adopted 主线。 |
