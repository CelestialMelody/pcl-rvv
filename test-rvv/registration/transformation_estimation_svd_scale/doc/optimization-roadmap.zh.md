# Optimization Roadmap

## 当前边界

当前 roadmap 只保留两件事：

- 已完成的生产边界。
- 未来要恢复时需要的新 scope。

详细历史放在下表。

| 状态 | 当前内容 |
| --- | --- |
| 已完成的生产边界 | ordered direct fused、row-source、correspondence sorted-copy `Scalar=float`、contiguous affine fast path、`Scalar=double` ordered / row-source / generic、custom layout double 取样、matrix-local helper simplification。 |
| 已关闭的路线 | staged-selected-cloud、dual-indexed target-sorted、dual-indexed 256K source-sorted-copy、sorted-copy double family selection。 |
| 仍需新 scope 才能恢复 | broader custom layout double、任意自定义点型、非法 index / correspondence、新 locality mitigation family、更广 sorted-copy double family selection。 |

| phase 组 | 当前结论 |
| --- | --- |
| Phase 031 | `direct-fused-scale-accum` 已成为 ordered-cloud-pair 的 adopted production behavior。 |
| Phase 043 | source-indexed、dual-indexed 和 correspondence row-source production patch 已采纳。 |
| Phase 045 | row-source locality / order profile 36 个 board case 全 positive；shuffle 明显慢于 contiguous / stride / reverse。 |
| Phase 046 / 047 | sorted-copy detail A/B 发现 correspondence 正向子边界，Phase 047 已接入并采纳 `Scalar=float` production probe。 |
| Phase 048 / 049 / 058 | staged-selected-cloud、dual-indexed target-sorted 和 dual-indexed 256K source-sorted-copy 已关闭。 |
| Phase 060 / 061 / 062 | contiguous affine index fast path 已收口为 adopted production behavior。 |
| Phase 063 到 Phase 071 | ordered double、row-source double、ordered generic double、row-source generic double 和 custom layout double samples 已收口为 adopted / adopted-by-user。 |
| Phase 072 / 073 / 075 | sorted-copy double public positive 只保留历史证据；detail A/B 证明它慢于 D64 gather，Phase 075 已回滚。 |
| Phase 050 | `matrix-local-scale-simplification` 仍是 adopted helper simplification。 |

当前 stop decision：Phase 075 后没有同范围、同 board budget 下的默认下一优化路线。表中剩余方向都需要新 scope 或新输入分布定义，不能作为当前 topic 的 unblocked next action。
