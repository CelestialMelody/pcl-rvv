# 文件级 RVV 优化候选评估（修订）

## 1. 方法说明

- 输入来源：`doc-rvv/library-screening/modules/*-function-triage.zh.md`（当前推进 16 模块）。
- 评估口径：全文件不漏，优先依据 `impl/*.hpp` 与 `src/*` 实现文件判断；`include/*.h` 用于补充内联实现与上下文。
- 排除口径：`3rdparty/**` 外部实现默认不纳入本轮候选。
- 纳入规则：文件级候选仅计 `high/mid`，`low` 不计入本轮统计。
- 推进说明：`gpu` 因结构差异较大暂缓推进，已从当前推进统计表移除（保留于模块评分文档中）。
- 数据结构模块口径补充：对 `kdtree/octree/search/geometry` 增加“树遍历分支+批量查询重排潜力”评估维度。
- 重评进度：当前推进 16 模块均已完成全覆盖重评。
