## 4. 筛选口径修正 / 复筛变化理由

1. 第二轮第 5 节中的 `diagnostic` 不是本轮固定分组。本轮只判断是否建议启动函数级评估；启动后的证据路径可为 `production-value evaluation`、`production-shaped diagnostic` 或 `component ablation`。
2. 已完成主题显示，只有局部 component 快、没有 public boundary 的候选默认不升级。DON、SHOT、normal_3d 都证明了局部收益会被 `Feature::compute()`、search、Eigen、小矩阵、sqrt 或 descriptor 输出稀释。
3. 已完成成功主题的共同点是有界：PFH、FPFH、MOI、organized edge 均有明确 gate、fallback、QEMU correctness、反汇编归属和板卡 public 证据。因此本轮建议项优先选择能复用这些形态的 caller-level 入口。
4. `features/src/pfh.cpp`、`features/src/ppf.cpp`、`features/src/cppf.cpp` 均无本地批量 loop。它们仍是重要 helper 证据来源，但不作为独立 topic 启动。
