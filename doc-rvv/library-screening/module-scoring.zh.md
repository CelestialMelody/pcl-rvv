# PCL 全库 RVV 模块评分（v2）

## 1. 评分模型

总分 = 计算收益（0-40） + 热度证据（0-25） + 可实现性（0-20） + 可验证性（0-15）。

- 高优：`>=70`
- 中优：`50-69`
- 低优：`<50`

## 3. 函数级首批清单的模块范围

函数级首批清单使用以下交集口径：

- 分层为中优或高优（`>=50`）；
- 且“是否纳入优化池”为“是”。

按当前评分，纳入文件级优化筛选清单的模块为：

`features`、`filters`、`geometry`、`gpu`、`io`、`kdtree`、`keypoints`、`ml`、`octree`、`recognition`、`registration`、`sample_consensus`、`search`、`segmentation`、`stereo`、`surface`、`tracking`

执行补充（重启版）：

- 主优化队列暂不含 `gpu`，先执行其余中高优模块。
- `gpu` 保留评分结果与候选记录，但在当前轮次后置单独研究。
